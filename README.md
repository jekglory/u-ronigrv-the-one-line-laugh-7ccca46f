`main.py` (pure Python standard library) writes one original funny line,
a single sentence of at most 200 characters, to `/output/entry.txt`.

The line:

> I bought noise-cancelling headphones to finally hear myself think — turns out I have nothing to say.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
